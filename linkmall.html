판매·지급

올리고, 팔고, 지급까지 자동으로.

  • 상품마다 미리보기(공개)와 잠금 정보(구매 후 공개)를 따로 설정
  • 재고 자동 지급: 한 줄에 하나씩 적어두면 구매할 때마다 순서대로 지급, 동시 구매에도 중복 지급 방지
  • 수량 선택, 품절 표시, 상품 사진 자동 축소 업로드
  • 공개·비공개(링크로만 열림) 설정, 상품 검색
  • 카테고리 만들기, 이름 변경, 상품 배치 (옆 메뉴에 표시)
  • 인당 구매 한도 제한 가능
  • 판매내역 검색: 상품명·구매자 회원번호·주문번호·기간으로 찾기, 옛날 주문까지 전부 조회 (건수·합계 금액 표시, 50건씩 넘겨보기)
  • 품절 예약: 품절 상품을 예약해 두면 재고가 들어올 때 예약한 순서대로 자동 구매 (포인트 선결제, 취소하면 환불)
  • 재입고 알림: 품절 상품에서 [알림 받기]를 누르면 재고가 들어올 때 푸시로 알려줘요 (푸시 알림을 켜 둔 경우) 무료

결제·포인트

상점마다 따로 쓰는 포인트. 수동 충전은 무료, 자동 충전은 Pro 기능이에요.

  • 상점별 포인트 결제 (1P = 1원), 포인트는 그 상점에서만 사용
  • 계좌 입금 충전 신청, 입금 사진 첨부, 수동 확인(판매자가 [입금 확인]을 누르면 포인트 지급) 무료
  • 자동 충전: 은행 입금 알림을 판매자 폰의 Automate 앱이 서버로 전달하고, 입금자명·금액이 신청과 같으면 포인트를 바로 지급 Pro
  • 이용권 키 자동 발급: 키 판매소에서 포인트를 충전하고 구매하면 그 자리에서 라이센스 키가 만들어져 바로 지급돼요. 기다릴 필요 없이 내 상점에서 바로 등록
  • 충전 확인 방식을 상점마다 수동 / 자동으로 선택, 자동으로 처리되지 않은 건은 언제든 수동 승인 가능
  • 같은 이름·같은 금액 신청이 겹치면 자동 처리를 건너뛰고 직접 승인하도록 안내
  • 판매자의 포인트 직접 조정과 내역 기록, 포인트·구매 내역 검색

단골 관리

많이 구매할수록 혜택이 쌓여요.

  • 칭호 시스템: 할인율(최대 20%), 페이백(최대 20%)
  • 누적 구매 금액 달성 시 자동 지급, 수동 지급·회수도 가능
  • 구매 후기와 별점, 상품 평점과 후기 수 표시
  • 문제 회원 차단 (구매·충전·문의 제한)

소통·알림

어디서든 바로 문의, 놓치는 주문 없이.

  • 문의 기능: 구매자 → 판매자, 회원·판매자 → 운영자
  • 상품 페이지, 구매 보관함, 상점 메뉴 어디서든 문의 가능
  • 판매자·운영자 전용 답변 화면, 답변 알림 푸시, 운영자 공지와 상점 공지(상단 고정)
  • 디스코드 웹훅 최대 5개, 웹훅마다 받을 알림 종류 선택 (판매, 입금 대기, 충전 신청, 재고 소진, 후기, 문의)
  • 알림 문장을 {변수}로 직접 꾸밀 수 있음
  • 웹·앱 푸시: 홈 화면에 추가하면 앱처럼 사용, 별도 설정 불필요

판매·프로모션

더 많이 팔리게 하는 도구들이에요.

  • 예약 판매·예약 공개: 정해 둔 시간에 상품이 자동으로 열리고 닫혀요 Plus
  • 기간 한정 세일: "3일간 20% 할인"처럼 기간을 걸면 끝나는 시각에 원래 가격으로 자동 복귀 Plus
  • 쿠폰: % 또는 원 할인, 사용 횟수·기간 제한, 1인 1회. Plus는 10개, Pro는 20개까지 Plus
  • 구매 후 자동 안내 문구: 상품마다 정해 두면 구매자의 주문 화면 맨 위에 사용 방법이 자동으로 보여서 같은 문의가 줄어요 Plus
  • 묶음 할인: "3개 이상 사면 개당 10% 추가 할인"처럼 정해 두면 구매 화면에서 합계가 자동으로 계산돼요. 칭호 할인·쿠폰과 같이 쓸 수 있어요 Pro
  • 충전 보너스 이벤트: "이번 주 충전 10% 추가 지급"처럼 기간과 최소 충전 금액을 정하면, 이벤트 기간에 신청한 충전에 보너스 포인트가 같이 들어와요. 충전 화면과 상점 맨 위에 안내가 떠요 Pro

통계·내보내기

숫자를 보고, 정리하고, 한 번에 처리해요.

  • 매출 통계 대시보드: 일·주·월별 매출, 인기 상품, 재구매율을 한눈에 Plus
  • 매출·주문 엑셀(CSV) 내보내기: 기간과 상품을 골라 받으면 엑셀에서 바로 열려요. 정산과 세금 정리에 쓰고, 지급된 키·계정 내용은 들어 있지 않아요 Plus
  • 상품 복사: 비슷한 상품을 버튼 한 번으로 복제해요. 재고(키·계정)는 복사하지 않고 비공개로 만들어져서 안전해요 Plus
  • 요일·시간대별 매출: 최근 90일 기준으로 가장 잘 팔리는 요일과 시간대를 보고 이벤트 시간을 잡아요 Pro
  • 주간 매출 리포트 푸시: 매주 월요일 오전 9시 이후, 지난주 매출·전주 대비·인기 상품을 알림으로 받아요 (언제든 끄거나 미리 받아볼 수 있어요) Pro
  • 상품 일괄 등록: 엑셀로 만든 CSV를 올리면 한 번에 200개까지 등록돼요. 양식을 내려받아 쓰고, 잘못된 줄은 이유와 함께 알려줘요 Pro

보호·팀·알림

상점을 안전하게, 여럿이 함께 지켜요.

  • 재고 부족 알림: 남은 재고가 내가 정한 개수 이하가 되면 푸시와 디스코드로 미리 알려줘요 Plus
  • 만료 임박 알림: 만료 7일·3일·1일 전에 알려줘서 갑자기 끊기지 않아요 Plus
  • 어뷰징 자동 차단: 충전·예약을 1시간에 10번 넘게 취소하거나 쿠폰 코드를 10번 넘게 틀리는 회원을 자동으로 막고 알려줘요. 입금이 확인된 충전은 세지 않아요 Pro
  • 직원 계정 5명: 직원마다 체크박스로 권한을 골라 줘요 (상품, 재고 열람, 판매내역, 충전 승인, 포인트 조정, 차단, 문의, 공지, 쿠폰). 이름·계좌·알림·꾸미기는 항상 주인만 바꿔요 Pro

꾸미기·한도

내 상점답게 꾸미고, 더 많이 만들어요.

  • 상점 꾸미기: 테마 색상, 로고, 배너를 내 마음대로 Plus
  • 공지 배너: 이벤트·점검 안내를 눈에 띄는 배너로 상점 맨 위에 띄우고 노출 기간을 정해요 Plus
  • 전용 주소: 나만의 상점 주소(/@이름)로 접속 Pro
  • PRO 뱃지·칭호 30개: 상점 이름 옆에 뱃지가 붙고, 칭호를 기본 10개에서 30개까지 만들 수 있어요 Pro
  • 상점 개수 확대: 기본 3개에서 Plus는 4개, Pro는 5개까지 Plus
NOTICE

시작 전에 알아두세요.

이용 안내
상점 만들기, 판매·지급, 포인트 결제, 수동 충전, 칭호, 문의, 알림 등 기본 기능은 모두 무료(Lite)예요. 더 필요하면 Plus(30일 3,000원) 또는 Pro(30일 5,000원) 이용권(라이센스 키)을 등록하세요. 키는 키 판매소에서 포인트로 사면 즉시 자동 발급되니 따로 연락하지 않아도 돼요.
자동 충전 환경
자동 충전은 안드로이드 폰에서 설정해요 (아이폰은 수동 사용). 입금 알림을 받는 폰이 켜져 있고 인터넷에 연결돼 있어야 하고, 폰이 꺼져 있는 동안 들어온 입금은 [입금 확인] 버튼으로 직접 처리하면 돼요.
참고
웹페이지를 열 때 나타나는 Render 메시지는 DB 시작 메시지이니 안심하고 사용하세요.
